场景预设

规则集

勾选需要的规则集并指定策略（DIRECT 直连 / PROXY 代理 / REJECT 拦截）。 标记「仅 mihomo」「仅 singbox」的规则集在另一内核的上游并不存在，切换内核时会自动置灰。

自定义规则

每行一条，语法 类型,值,策略，策略可选 DIRECT / PROXY / REJECT。
类型：DOMAIN、DOMAIN-SUFFIX、DOMAIN-KEYWORD、IP-CIDR、IP-CIDR6、GEOSITE、GEOIP。
示例：DOMAIN-SUFFIX,example.com,DIRECT、IP-CIDR,1.2.3.0/24,PROXY、GEOSITE,bilibili,DIRECT

自定义规则集

添加远程规则订阅（mihomo 支持 .mrs/.yaml/.txt，sing-box 建议 .srs）。

面板自更新

        
当前版本 。更新流程：下载 → 可执行验证 → sha256 校验 → 备份旧文件 → 原子替换 → 无缝重启，数据与配置不受影响。

        

          

          

        

        
        
        
      

      

        
组件更新与版本管理

        
面板与三个内核均可更新/降级到任意版本。每一步都有安全保护：新二进制可执行验证 → 用它校验当前配置 → 备份旧版本 → 原子替换 → 重启 + 健康检查，任一环节失败自动回滚，服务不中断。

切换内核

    

      流程：预检新内核配置（校验不过则不会切换）→ 停旧内核 → 启动新内核 → 健康检查。
      启动失败会自动回滚到原内核，全程服务不中断（仅切换瞬间约 1 秒）。
