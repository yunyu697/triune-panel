订阅输出

        

          外部节点是全局的：打开后，每一个用户的订阅里都会带上下面这些节点。
          它们既不受本机配额约束、也不经过本机内核（是别人的服务器），所以默认关闭。

面板 HTTPS
          —
        

        

          不需要域名：面板自己签一张证书（含本机全部 IP），直接在
          https://服务器IP:端口 上加密，登录密码与 token 不再明文过网。

          data/tls/panel.key，面板识别出不是自己签的，重启也不会覆盖。

登录二次验证（2FA）

        
在账号密码之外追加一道验证。开启后登录需输入第二步凭据，验证失败同样计入防爆破锁定。两种方式二选一。

        

          

            方式一：验证器 App（TOTP 动态口令）
            
Google / Microsoft Authenticator、1Password、FreeOTP 等均支持。生成密钥后可直接扫码绑定，也可手动输入密钥（需设备时间准确）。

            

              

                
                
                

                  扫一扫绑定
                  

                    验证器 App →「添加账号 / 扫描二维码」，对着左侧扫一下即可。

                    设备扫不了码时，再手动输入下方密钥。设备时间不准会让动态口令一直被判错。
                  

                  

                  
                

              

              

                

                

                

              

              

                
                
              

            

            
          

          

            方式二：邮箱验证码
            
登录时向下方邮箱发送 6 位验证码（5 分钟有效）。需配置可发信的 SMTP 通道。

            

              

              

              

              

              

              

            

            

              
              
            

          

        

        

          
        

      

      

        
面板自更新

        
当前版本 。更新流程：下载 → 可执行验证 → sha256 校验 → 备份旧文件 → 原子替换 → 无缝重启，数据与配置不受影响。

        
        

          磁盘上的二进制已经是 ，但进程仍在运行 
          

          

          

            手动重启一次即可生效：
            sudo systemctl restart triune-panel
            
          

        

        

          
        

        

          面板会盯着自己的二进制文件：一键脚本 cp、手工 mv、容器里 docker cp、
          systemd 只换了文件没重启——只要它稳定地变成了另一个版本，几秒内就会自己 exec 过去，监听与数据无缝衔接。
          同一版本最多试 2 次，失败会留下说明，不会变成重启风暴。
          容器编排 / supervisor 下想自己决定重启时机时，关掉这个开关。
        

        

          

          

        

        
        
        
      

      

        
组件更新与版本管理

        
面板与三个内核均可更新/降级到任意版本。每一步都有安全保护：新二进制可执行验证 → 用它校验当前配置 → 备份旧版本 → 原子替换 → 重启 + 健康检查，任一环节失败自动回滚，服务不中断。

Reality 握手目标择优

    

      从这台服务器逐个真握手，量的是客户端握手实际要走的那段网络。
      判据三条：能连上、支持 TLS 1.3、证书与 SNI 对得上——三者缺一，看上去能连、
      实际会露馅或根本用不了。每行一个目标，可写成 域名 或
      域名:端口，最多 16 个。
    

    

      另外一句实话：延迟低不等于安全。被大量面板填成默认值的目标（例如
      www.apple.com）反而更容易被针对性封锁，xray 在启动时也会这么提醒。
      优先选离服务器近、别人不常填、且证书正常的大站。
    

    

      「取 SNI」会读该目标的证书，把里面每个域名逐个真握手验证一遍——REALITY 只认
      serverNames 里的名字，而该填哪些只能问证书。验过的可以一键并入。
